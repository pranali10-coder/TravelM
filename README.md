# ✈️ Travel Management System (Java + JDBC)

## 🚀 Overview
A full-stack web-based Travel Management System developed using Java Servlets and JDBC.  
This system enables users to explore and book travel packages while providing an admin panel to manage bookings, tours, galleries, and customer interactions.

---

## 🧩 Architecture
This project is divided into two main modules:

- **Travel/** → User Panel (Frontend)
  - Browse tours
  - View gallery
  - Send inquiries
  - Book travel services

- **TravelAdmin/** → Admin Panel (Backend)
  - Manage tours
  - Manage gallery & videos
  - Handle customer inquiries
  - Admin authentication

---

## ⚙️ Tech Stack
- Java (Servlets)
- JDBC (Database Connectivity)
- MySQL
- HTML, CSS, JavaScript
- Apache Tomcat Server

---

## 💡 Key Features
- User-friendly travel booking interface
- Admin dashboard for full system control
- Dynamic data handling using JDBC
- Modular architecture (separate frontend & admin)
- Gallery & video management system

---

## ▶️ How to Run
1. Install Apache Tomcat Server
2. Copy both folders (`Travel`, `TravelAdmin`) into Tomcat `webapps` directory
3. Import database using `.sql` file
4. Configure database connection in Java code
5. Start Tomcat server

### 🔗 Access URLs:
- User Panel: http://localhost:8080/Travel
- Admin Panel: http://localhost:8080/TravelAdmin
